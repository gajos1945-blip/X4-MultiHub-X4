X4 MultiHub v0.7-dev-fix1
=========================

GitHub result:
- C++/PlatformIO build: SUCCESS
- firmware.elf: created
- firmware.bin: created
- failure occurred only at:
  "5/7 Validate application image and ranges"

Root cause:
release_guard.py correctly required the marker:
  NOT IMPLEMENTED v0.7

but MultiHubActivity.cpp still contained:
  NOT IMPLEMENTED v0.6

Therefore the finished BIN could not contain the required v0.7 marker and
the safety validator intentionally blocked artifact publication.

Fix:
- updated the Settings placeholder from v0.6 to v0.7,
- added a regression test that checks every REQUIRED_MARKERS entry exists
  somewhere in the firmware overlay source before PlatformIO compilation.

No flash size, offset, partition table, application address, bootloader,
ota_data or full-flash assumptions were changed.

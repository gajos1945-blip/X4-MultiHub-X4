X4 MultiHub v0.5-dev-fix1
=========================

Observed GitHub Actions compile error:
  MarketStore.cpp:51:21:
  class HalFile has no member named 'readString'

Cause:
CrossPoint's HalFile abstraction is not Arduino File and does not expose
readString().

Fix:
Replaced HalFile::readString() with the same supported API style already used
elsewhere in this project:
  file.available()
  file.read()

The read is bounded to 2048 bytes before JSON parsing.

No flash size, offsets, partition layout, application address, bootloader or
OTA data assumptions were changed.

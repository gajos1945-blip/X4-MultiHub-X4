X4 MultiHub Daily Planner

Pliki runtime tworzone automatycznie:
  /.x4-multihub/planner/tasks.jsonl
  /.x4-multihub/planner/active_date.txt

W v0.4-dev data aktywnego dnia jest ustawiana recznie w formacie YYYY-MM-DD.
Nie zgadujemy daty i nie udajemy, ze RTC/NTP jest zweryfikowane na fizycznym X4.

Sterowanie:
- Dzien -> ustaw date
- Poprzedni / Nastepny dzien -> zmiana daty
- Dodaj zadanie -> nowy tytul
- klik zadania -> wykonane / otwarte
- dlugie przytrzymanie -> szczegoly zadania:
  status, priorytet, tytul, notatka, data, usun
